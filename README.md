# kbdkid5

A wireless split keyboard with Kailh Choc v1 switches on hotswap sockets and a nice!nano v2 per half, the successor of [kbdkid4](https://github.com/Tubbles/kbdkid4). The PCB carries only the switch matrix. The nice!nano, power switch, reset button and battery connector are wired by hand and mounted in the 3D-printed tray, which makes the half smaller and lower than kbdkid4's. A slanted inner edge lets the two halves join with magnets and steel dowel pins into one Alice-like board.

The design, with every dimension, is in [DESIGN.md](DESIGN.md). The part choices and their sources are in [doc/components.md](doc/components.md), and the plan is in [PLAN.md](PLAN.md). The PCB itself is not designed yet. For now a printed mock stands in for it.
